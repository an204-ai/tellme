# Tài sản thương hiệu Tellme

Quy chuẩn thương hiệu được ghi tại [docs/DESIGN.md](../../docs/DESIGN.md). Ảnh bảng nhận diện gốc được lưu ở [references/brand-board.png](references/brand-board.png) để đối chiếu; không đưa bản sao không dùng vào thư mục public.

| Tệp | Mục đích |
| --- | --- |
| `apps/web/public/brand/logos/tellme-wordmark-on-light.png` | Wordmark xanh dùng trên nền sáng. |
| `apps/web/public/brand/logos/tellme-wordmark-on-dark.png` | Wordmark trắng dùng trên nền tối. |
| `apps/web/public/brand/logos/tellme-symbol-on-light.png` | Biểu tượng xanh dùng trên nền sáng. |
| `apps/web/public/brand/logos/tellme-symbol-on-dark.png` | Biểu tượng trắng dùng trên nền tối. |
| `apps/web/src/app/icon.png` | Favicon từ biểu tượng xanh trên nền trong suốt. |

Landing page có bản sao của bốn logo tại `tellme-landing/public/brand/logos/` để có thể deploy độc lập. Bộ nguồn mới vẫn được lưu ở thư mục gốc `logo-collection/`; thư mục `logo/` cũ không có trong workspace.
