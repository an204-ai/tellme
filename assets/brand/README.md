# Tài sản thương hiệu Tellme

Nguồn nhận diện là [brand-board.png](references/brand-board.png), ảnh do chủ dự án cung cấp. Quy chuẩn được ghi tại [docs/DESIGN.md](../../docs/DESIGN.md).

| Thư mục | Nội dung |
| --- | --- |
| `references/` | Ảnh nhận diện gốc để đối chiếu; không dùng nguyên bảng này làm logo trong ứng dụng. |
| `logos/` | Nơi lưu logo chính và logo âm bản khi có file xuất riêng. |
| `icons/` | Nơi lưu biểu tượng đơn sắc và bản gốc app icon khi có file xuất riêng. |
| `fonts/` | Nơi lưu font và giấy phép khi có bộ font dùng cục bộ. |

Hiện chỉ có ảnh tham chiếu. Các thư mục còn lại là chỗ chuẩn bị, chưa có logo vector, font hoặc icon được trích xuất hay tạo mới.

File dùng trực tiếp trên web được đặt ở `apps/web/public/brand/`. File dành riêng cho Expo được đặt ở `apps/mobile/assets/`; cấu hình hiện có nhắc tới `icon.png`, `splash.png` và `adaptive-icon.png`, nhưng các file này chưa được cung cấp. Không thay chúng bằng toàn bộ ảnh bảng nhận diện.
