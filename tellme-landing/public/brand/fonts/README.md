Fredoka Bold 700, by the Fredoka Project Authors; SIL Open Font License 1.1 (see Fredoka-OFL.txt).

Downloaded from the official Google Fonts CSS API on 2026-11-02. The 4.2 KB TrueType subset contains only the letters used in Tell / me / now and their uppercase variants. Use it only for the brand intro; the rest of the UI retains its existing fonts.
